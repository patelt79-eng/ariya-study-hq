# Content to check

The booklet mostly lists topic **names**. Everything below was written from the standard KS3 England curriculum (AQA-aligned for Science), so please check it against Ariya's exercise books and knowledge organisers. Fix anything in `src/content/<subject>.ts` (see README).

## Timetable
- Copied from the booklet table for all nine classes. **7A3** is Maths Mon 16, Science Tue 17, English Thu 19, RE Fri 20, Geography Tue 24, History Wed 25 Nov.
- The booklet grid has no Maths date for 7B3 on Wed 25 and no Science/Maths gaps for some classes. The app shows a note if a class has no date for a subject.

## Maths
- **Calculator:** I assumed the assessment is **non-calculator**. If a calculator is allowed, nothing breaks; the questions are just easier.
- **MathsWatch clip numbers** are shown exactly as the booklet gives them (G13, G14, G16, G17, R1a, R1b, R5a, R5b, R8, "39, 105" for recipes, "106" for currency). The booklet's clip column was a little ambiguous for the last few rows, so please check the recipe and currency clips.
- "Sets 1–2 only" is shown on *ratio given the difference* (R8) and *currency conversion* (106), as in the booklet.
- **Vertically opposite angles** were added to the angle-rules learn card and 2 questions. They are part of the usual G13/G14 content, but the booklet only mentions "straight line, around a point".
- Exchange rates in questions (£1 = €1.20, $1.25 and so on) are made-up practice rates, not real ones.
- Learn card on parallelograms and kites (opposite angles equal; kite has one pair of equal angles) goes slightly beyond the booklet's "angles in quadrilaterals".
